## Design Context

### Users
Supervisors and superusers managing student progress, attendance, course completion, and monitoring workflows. They are typically in an operational context and need to scan many records quickly without losing confidence or control.

### Brand Personality
Polished, professional, and reassuring. The interface should feel organized and trustworthy rather than loud or flashy.

### Aesthetic Direction
A clean academy command center with a hybrid table-and-panel layout. Favor calm surfaces, restrained borders, strong spacing rhythm, and clear typographic hierarchy. Avoid visual noise, nested cards, and decorative chrome.

### Design Principles
- Prioritize scanability over decoration.
- Keep one clear action path per data cluster.
- Use spacing and typography before borders and backgrounds.
- Make labels and actions explicit and concise.
- Preserve dense operational data without making it feel crowded.

### Brand Design System & Palette (Deep Indigo & Tech Slate)
To unify the visual identity across the front-end pages, base templates, and Django Unfold admin panel, all future UI enhancements must strictly adhere to the following design system palette and guidelines:

#### 1. Color Palette Tokens (CSS variables in `global_ux.css`)
- **Brand Primary (Deep Indigo)**: `#6366f1` (Indigo 500) - For branding, active states, and primary actions.
- **Brand Primary Hover**: `#4f46e5` (Indigo 600).
- **Brand Secondary (Tech Slate)**: `#0f172a` (Slate 900) - For dark accents, dense backgrounds, and heavy titles.
- **Accent Color (Electric Violet)**: `#8b5cf6` (Violet 500) - For interactive highlights, links, and focus rings.
- **Accent Soft**: `#f5f3ff` (Violet 50) - For hover backgrounds, highlighted list items, and selected states.

#### 2. Tailwind Config Extended Theme (in `base_rtl.html`)
```javascript
colors: {
    primary: {
        DEFAULT: '#6366f1',
        hover: '#4f46e5',
        light: '#f5f3ff',
    },
    secondary: '#0f172a',
    accent: '#8b5cf6',
}
```

```python

        "500": "99 102 241",  # Brand Indigo (#6366f1)
```

#### 4. Interaction & Motion Guidelines
- **Transitions**: Apply uniform transition speeds: `all 0.25s cubic-bezier(0.4, 0, 0.2, 1)` to prevent abrupt visual changes.
- **Focus Rings**: All interactive controls must show visible, high-contrast focus rings: `2px solid var(--brand-primary)` with `outline-offset: 2px` for outstanding accessibility.
- **Glassmorphism**: Use backdrop filters for overlays and sticky headers with `rgba(255, 255, 255, 0.85)` and `backdrop-filter: blur(12px)`.
